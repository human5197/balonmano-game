# Balonmano 3D

Prototipo de juego de balonmano en 3D hecho en 2 días conversando con Claude Code, sin ser desarrollador. No es el mejor juego del mundo, pero se puede jugar y tiene reglas reales: pasos, bote, áreas y portero.

Forma parte de mis [experimentos con IA](https://github.com/human5197): ahí cuento qué quería probar, cómo lo hice y qué salió.

## Jugar en local

```
npm install
npm run dev
```

Y abre la dirección que aparece (normalmente http://localhost:5173).

Hecho con Three.js, TypeScript y Vite. Los modelos 3D son de [Kenney](https://kenney.nl) (licencia CC0, ver `public/models/KENNEY-LICENSE.txt`).
